# Managed font catalog

These faces were copied from the official Google Fonts repository at commit
`ec626514f79f831f1ab848a82114a0ce7e2d6372`. Each family directory retains its
upstream `OFL.txt`. Exact face SHA-256 values are part of
`LinearTrace.Visualization.FontCatalog`; compilation fails if a bundled file
does not match the catalog.

The preset catalog contains Inter, Source Sans 3, Atkinson Hyperlegible Next,
Space Grotesk, Source Serif 4, Literata, JetBrains Mono, and IBM Plex Mono.
“JetBrains Mono NL” is the normal JetBrains Mono variable face shaped with
`liga=0` and `calt=0`, not a rewritten font binary.
